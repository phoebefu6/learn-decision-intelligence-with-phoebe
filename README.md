Six sessions on the judgment layer: decisions before data, calibration measured live, superforecasting habits with honest citations, uncertainty you can promise, value of information, and communication that keeps trust.

**Live:** https://phoebefu6.github.io/learn-decision-intelligence-with-phoebe/

- Running artifact: a six-section decision memo (default, criteria, calibrated estimates, base rates, information verdict, communication)
- Every claim verified to source with misquote traps taught on-page: the chimp line with Tetlock's own correction, the press-sourced "30% vs analysts" claim retired, the ~45-minute (not one-hour) training result
